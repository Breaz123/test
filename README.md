# Kaliber Maatwerk Intranet

Deze repository bevat een eenvoudige demonstratie van een intranet dashboard voor Kaliber Maatwerk. Het dashboard is een statische webpagina opgebouwd met HTML, CSS en JavaScript.

## Bestandsoverzicht

- `index.html` – de hoofdpagina van het intranet
- `styles.css` – basisopmaak voor de pagina
- `script.js` – eenvoudige scripts om voorbeeldgegevens te laden

## Gebruik

Open `index.html` in een webbrowser om het dashboard te bekijken.
